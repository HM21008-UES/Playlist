# Sistema de Gestión de Playlist Musical

-- El  proyecto consistirá en el desarrollo de un sistema de gestión de playlists musicales implementado en Python, orientado a la aplicación de estructuras de datos lineales y no lineales.

-- El sistema permitirá administrar canciones, gestionar una cola de reproducción, almacenar historial musical y organizar géneros mediante diferentes estructuras estudiadas en la asignatura Manejo de Estructura de Datos.

-- Además, el proyecto integrará listas enlazadas, pilas, colas, recursividad y árboles dentro de una misma solución funcional, permitiendo relacionar la teoría con una aplicación práctica y estructurada.

# Objetivo general
Desarrollar un sistema de gestión musical en Python que permita aplicar estructuras de datos lineales y no lineales para administrar playlists, reproducciones e historial de canciones.

# Estructuras de datos a utilizar

## Lista enlazada:
La lista enlazada permitirá almacenar canciones dinámicamente dentro de la playlist, facilitando recorridos secuenciales e inserciones de nuevos elementos.

## Cola:
La cola permitirá administrar la reproducción musical siguiendo el modelo FIFO, simulando el comportamiento de reproducción continua.

## Pila:
La pila permitirá almacenar el historial de canciones reproducidas utilizando el principio LIFO.

## Árbol:
El árbol permitirá representar jerarquías de géneros y subgéneros musicales de forma organizada.

## Recursividad:
La recursividad permitirá recorrer estructuras dinámicas como listas enlazadas y árboles de manera eficiente.

# Funcionalidades del sistema

#### El sistema permitirá:

- Agregar canciones a la playlist.
- Mostrar canciones almacenadas.
- Agregar canciones a la cola de reproducción.
- Reproducir canciones.
- Visualizar historial musical.
- Mostrar jerarquía de géneros musicales.
- Guardar información en formato JSON.
